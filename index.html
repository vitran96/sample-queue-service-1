Clinic Queue

Interactive Multi-Screen Browser Demo

How to Run the Demo

This demo runs entirely in your browser without a backend server. Open the four screens below in separate tabs or windows of the same browser profile. They share state live through localStorage and Web Locks just like real hardware devices would.

Popup blocked: Please allow popups for this site in your browser to open all four windows at once, or click the individual buttons below.

1. Kiosk

Patient touch-screen: scan/type ID, get ticket, QR code & print.

2. Staff Panel

Counter PC / tablet: PIN gate (1234), Call next, recall, no-show, queue list.

3. Waiting Display

TV display: now serving, up next, no-shows, sound chime & flash animation.

4. Patient Phone

Mobile view: live place tracking, "You're next", call notifications.
